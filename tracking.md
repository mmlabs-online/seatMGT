> `Constraint (Depends on)` lists feature codes that must exist first. Open decisions are flagged in **Note**.

> **Status legend:** `[x]` = built (backend + UI, verified) · `[~]` = partial (see Note — usually backend/server action done but no UI, or display-only) · `[ ]` = not built yet.
